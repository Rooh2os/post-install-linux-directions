# Post install Linux directions

This is a script I made to install the software and configuration files I need when setting up my Linux distros (mostly just [Linux Mint](https://linuxmint.com/)).

Please use this as you wish (following the [License](LICENCE) of course) and make your own install scripts to aid your process of installation

> [!CAUTION]
> The script will delete your current config files in your home directory and replace them with the ones in the [files](files) directory

Huge thanks to all of the amazing devs that made the software this script installs
